SYSTEM PWA — перша версія
================================

ЩО ЦЕ
Локальний PWA-прототип SYSTEM: RPG-стиль, щоденні квести, XP, рівень,
лічильник днів до 219, запис ваги й талії та тижневий план тренувань.

ВАЖЛИВО ПРО ДАНІ
- Дані зберігаються локально у localStorage браузера.
- У цій версії немає акаунтів, сервера, синхронізації чи резервної копії.
- Не очищайте дані браузера, якщо хочете зберегти записи.
- Не використовуйте цю версію для збору персональних даних інших користувачів.

ЯК ЗАПУСТИТИ НА WINDOWS
1. Розпакуйте ZIP у папку, наприклад C:\SYSTEM_PWA.
2. Відкрийте цю папку у Провіднику.
3. Клацніть адресний рядок, введіть cmd і натисніть Enter.
4. У консолі виконайте:
   py -m http.server 8000
   Якщо команда py не працює, спробуйте:
   python -m http.server 8000
5. На комп'ютері відкрийте:
   http://localhost:8000

Не закривайте консоль, поки тестуєте локальний сайт.

ЯК ВІДКРИТИ НА ANDROID
Щоб інсталювати PWA як застосунок, сайт має бути розміщений через HTTPS.
Локальна адреса localhost на ПК не відкриється автоматично на телефоні.
Коли опублікуєте файли на HTTPS-хостингу:
1. Відкрийте URL у Chrome на Android.
2. Відкрийте меню ⋮.
3. Виберіть "Встановити застосунок" або "Додати на головний екран".

НАСТУПНІ ЕТАПИ
1. Перевірити першу версію на ПК і телефоні.
2. Додати налаштування профілю та реальні дати старту програми.
3. Додати детальні тренування, історію замірів і резервний експорт.
4. Перед запуском для інших користувачів спроєктувати захищені акаунти,
   синхронізацію, політику конфіденційності та видалення даних.
5. За потреби підготувати Android APK через відповідний пакувальник.

Це прототип, а не медичний пристрій чи персональна медична рекомендація.
